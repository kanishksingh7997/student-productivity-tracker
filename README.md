# Student Productivity Tracker

A simple Python-based productivity tracker that helps students manage tasks and record daily productivity.

## Features

* Add tasks with subject and task title
* View all tasks
* Mark tasks as completed
* Delete tasks
* View task summary
* Log daily study hours
* Log coding hours
* Log sleep hours
* Record completed assignments
* Calculate a productivity score out of 100
* View productivity reports and average score
* Save task and productivity data using text files

## Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* File Handling
* Input Validation
* `datetime`

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python simple_productivity_tracker.py
```

## Data Files

The program automatically uses:

* `tasks.txt` — stores task information
* `productivity_log.txt` — stores daily productivity records

These files are created when the program saves data.

## Productivity Score

The program calculates a score out of 100 using:

* Study hours
* Coding hours
* Assignments completed
* Sleep hours

The program also limits the contribution of individual activities and keeps the final score between 0 and 100.
